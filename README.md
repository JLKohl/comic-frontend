# Overview

This site is the front end for my Comic "Wildly Imaginative". Right now it is displaying the name and details of a comic on a site with TypeScript. The full stack of this site is MySQL --> C# --> TypeScript. 

With this site I am learning how to connect my back end C# to the front end with TypeScript. 


[TypeScript Video](https://youtu.be/5kf7ujksJes?si=ed_NH72xCgW1FDjG)

# Development Environment

## Tools Used
- [Node.js](https://nodejs.org/) (v26.4.0): runs JavaScript tools on my computer
- [npm](https://www.npmjs.com/) (11.17.0): installs packages
- [Vite](https://vite.dev/) (8.3.4): dev server and build tool
- [Claude Code](https://claude.com/download) (Claude Opus 5.5): AI assistant used in VS Code for explaining TypeScript concepts, finding referance code for concepts that were not understood and spell checking work. 

## Language and Libraries
- [TypeScript](https://www.typescriptlang.org/download/)(6.0.3)

## How to Run
1. Start the C# API (`dotnet run`)
2. `npm install`
3. `npm start`, then open localhost:5173
4. `npm run check` to test the API from the terminal
