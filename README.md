# Overview

This site is the front end for my Comic "Wildly Imaginative". Right now it is displaying the name and details of a comic on a site with TypeScript. The full stack of this site is MySQL --> C# --> TypeScript. 

With this site I am learning how to connect my back end C# to the front end with TypeScript.
